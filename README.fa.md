# 📖 درباره

**آموزش هوش مصنوعی و یادگیری ماشین** یک مخزن آموزشی با شش نوت‌بوک تعاملی Jupyter است که ایده‌های اصلی هوش مصنوعی و یادگیری ماشین امروز را درس می‌دهد.

مسیر از این شروع می‌شود که مدل چطور از داده یاد می‌گیرد. بعد یادگیری نظارت‌شده و بدون نظارت، شبکه عصبی، یادگیری عمیق با شبکهٔ کانولوشنی، و در آخر مدل‌های زبانی بزرگ مثل GPT و BioGPT می‌آید.

خیلی از مثال‌ها از دادهٔ سلامت و زیست‌پزشکی هستند: پیش‌بینی سرطان پستان، بیماری قلب، تصویر سی‌تی مغز، سیگنال ضربان از گجت پوشیدنی، ژنومیک و متن زیست‌پزشکی. درس عملی می‌ماند، نه فقط تعریف.

هر نوت‌بوک توضیح کوتاه، مثال اجرایی و گردش کار واقعی دارد تا یادگیری با اجرا باشد.

> **جمله کوتاه:** *مخزن عملی هوش مصنوعی و یادگیری ماشین که یادگیری نظارت‌شده، بدون نظارت، شبکه عصبی، یادگیری عمیق و مدل زبانی را با نوت‌بوک Jupyter پوشش می‌دهد.*

# ▶️ روش استفاده

### راه ۱ — دیدن در گیت‌هاب

1. این مخزن را باز کن.
2. روی هر فایل `.ipynb` کلیک کن.
3. سلول‌ها و مثال‌ها را بخوان.

### راه ۲ — اجرای محلی

```bash
git clone https://github.com/sadra-hatami/AI-ML-Training.git
cd AI-ML-Training
```

بسته‌های رایج:

```bash
pip install notebook pandas numpy scikit-learn matplotlib tensorflow pyod transformers sacremoses
jupyter notebook
```

فایل درس‌ها را یکی‌یکی باز کن و سلول‌ها را اجرا کن.

### راه ۳ — Google Colab

هر نوت‌بوک را در [Google Colab](https://colab.research.google.com/) بارگذاری کن و بدون نصب محلی در مرورگر اجرا کن.

بعضی درس‌های بعدی به TensorFlow یا Hugging Face Transformers نیاز دارند. اگر Colab خواست، همان‌جا نصب کن.
