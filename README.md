# 📖 About

**Introduction to AI and Machine Learning** is an educational repository with six interactive Jupyter notebooks that teach the core ideas of artificial intelligence and modern machine learning.

The path starts with how models learn from data, then moves through supervised and unsupervised learning, neural networks, deep learning with convolutional networks, and finally large language models such as GPT and BioGPT.

Many examples use biomedical and healthcare data — including breast cancer prediction, heart disease, brain CT images, wearable heart-rate signals, genomics, and biomedical text — so the lessons stay practical for data science and precision-medicine study.

Each notebook includes short explanations, runnable examples, and real workflows so you can learn by doing, not only by reading.

> **Tagline:** *A practical AI and machine learning repository covering supervised learning, unsupervised learning, neural networks, deep learning, and LLMs through interactive Jupyter Notebooks.*

# 📚 Lessons

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [part1_Introduction_to_AI_ML.ipynb](part1_Introduction_to_AI_ML.ipynb) | AI vs rule-based programs, training and test sets, models, accuracy / precision / recall / F1, confusion matrix, breast cancer prediction with logistic regression |
| 2 | [part2_Introduction_to_Supervised_Learning.ipynb](part2_Introduction_to_Supervised_Learning.ipynb) | Labeled data, features and target, heart disease classification, standardization, supervised workflow, biomedical applications |
| 3 | [part3_Introduction_to_Unsupervised_Learning.ipynb](part3_Introduction_to_Unsupervised_Learning.ipynb) | Unlabeled data, clustering, K-means, anomaly detection with KNN, wearable heart-rate outliers |
| 4 | [part4_Introduction_to_Neural_Networks.ipynb](part4_Introduction_to_Neural_Networks.ipynb) | Neurons, layers, weights, activation functions, backpropagation, MNIST digits with Keras |
| 5 | [part5_Introduction_to_Deep_Learning.ipynb](part5_Introduction_to_Deep_Learning.ipynb) | CNNs, convolution, filters, pooling, brain CT classification, one-hot DNA sequences, TFBS prediction |
| 6 | [part6_Introduction_to_Large_Language_Models.ipynb](part6_Introduction_to_Large_Language_Models.ipynb) | Transformers, self-attention, prompting, GPT, fine-tuning, BioGPT, prompt engineering |

### Suggested order

1. Start with **Part 1** to understand how machine learning works.
2. Continue with **Part 2** to train a supervised model.
3. Use **Part 3** to find patterns without labels.
4. Learn network building blocks in **Part 4**.
5. Train image and sequence models in **Part 5**.
6. Finish with **Part 6** to work with large language models.

# ▶️ How to Use

### Option 1 — Open on GitHub

1. Open this repository.
2. Click any `.ipynb` file.
3. Read the cells and review the examples.

### Option 2 — Run locally

```bash
git clone https://github.com/sadra-hatami/AI-ML-Training.git
cd AI-ML-Training
```

Then install the common packages:

```bash
pip install notebook pandas numpy scikit-learn matplotlib tensorflow pyod transformers sacremoses
jupyter notebook
```

Open the lesson files one by one and run the cells.

### Option 3 — Google Colab

Upload any notebook to [Google Colab](https://colab.research.google.com/) and run it in the browser with no local setup.

Some later notebooks need extra packages such as TensorFlow or Hugging Face Transformers. Install them in the notebook if Colab asks for them.
